# Тестирование

## Стек

- `pytest` — запуск тестов;
- `pytest-cov` — покрытие;
- Flask test client — HTTP-запросы без реального сервера;
- временная SQLite-база в `tmp_path` для изоляции тестов.

## Запуск

```powershell
# Все тесты
pytest -v

# С покрытием
pytest --cov=. --cov-report=term-missing

# HTML-отчёт покрытия
pytest --cov=. --cov-report=html
```

HTML-отчёт появится в `htmlcov/index.html`.

## Структура тестов

| Файл | Что проверяет |
|---|---|
| `tests/conftest.py` | фикстуры приложения, временная БД, пользователи, объекты, helper `login` |
| `tests/test_auth.py` | регистрация, вход/выход, дубликаты, смена пароля, защита дашборда |
| `tests/test_properties.py` | создание и редактирование объектов, версии тарифов, права ролей, коды приглашения, привязка арендаторов |
| `tests/test_readings.py` | формула расчёта, базовая запись, запрет уменьшения, дубликаты дат, выбор тарифа по дате, пересчёт истории, редактирование/удаление, оплата |

## Как устроена изоляция

Фикстура `app` создаёт приложение с конфигурацией:

```python
{
    "TESTING": True,
    "DATABASE": str(tmp_path / "test.db"),
    "SECRET_KEY": "test-secret",
    "WTF_CSRF_ENABLED": False,
    "LOG_FILE": str(tmp_path / "test.log"),
}
```

Для каждого теста создаётся новая БД и новые пользователи:

- `owner1` / `tenant1` — доступ к первому объекту;
- `owner2` / `tenant2` — второй объект для проверки изоляции.

Тест CSRF отдельно создаёт приложение с `WTF_CSRF_ENABLED=True` и проверяет,
что POST без токена отклоняется.

## Что важно проверять при доработках

- права арендодателя и арендатора на объекты и показания;
- выбор тарифа по дате показания;
- пересчёт всех последующих счетов при изменении старых показаний;
- снятие оплаты при изменении суммы;
- округление денег и расхода;
- CSRF и экранирование пользовательского ввода;
- экспорт CSV с корректной кодировкой.

## CI

`.github/workflows/tests.yml` запускает тесты на Ubuntu с Python 3.12 при
каждом push в `main`/`master` и каждом pull request:

```yaml
- name: Run tests with coverage
  run: pytest -q --cov=. --cov-report=term-missing
```

Секреты и внешние сервисы не требуются.
