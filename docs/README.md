## Обозначения

- `owner` — арендодатель, владелец объекта;
- `tenant` — арендатор, привязанный к объекту;
- ГВ — горячая вода;
- ХВ — холодная вода;
- `com1` — тариф водоотведения холодной воды;
- `com2` — тариф общего водоотведения.
